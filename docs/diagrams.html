4. Build-Time vs Client-Runtime Data Flow

Temporal flow: build-time fetches WordPress articles and statically generates tema pages, then at runtime the browser hydrates charts by fetching JSON via useSWR.

sequenceDiagram participant WP as WordPress (eubureauet.dk) participant Script as fetch-articles.mjs (build-time) participant FS as data/ folder participant Next as Next.js SSG (npm run build) participant Browser as Browser (Client) rect rgb(230, 245, 230) Note over WP,FS: BUILD-TIME (prebuild + build) WP->>Script: REST API /wp-json/wp/v2/posts?_embed Script->>Script: paginate, decode HTML entities alt API fails WP->>Script: RSS /feed/ (fallback) Script->>Script: parse XML end Script->>FS: write articles.json FS->>Next: read data/themes/*.json Next->>Next: generateStaticParams() → [energi, forsvar, miljoe] FS->>Next: read articles.json (filter by tags) FS->>Next: read latest_votes.json + All_Pairwise_coalitions.json Next->>Next: generateSubDescription() per visualisation Next->>Next: export static HTML + JSON to /out end rect rgb(230, 235, 250) Note over Browser,FS: CLIENT RUNTIME Browser->>Browser: Load static HTML page Browser->>FS: useSWR → /data/All_Winning_coalitions.json Browser->>FS: useSWR → /data/All_Group_wins.json Browser->>FS: useSWR → /data/group-tooltips.json Browser->>FS: useSWR → /data/committee_and_group_names.json FS-->>Browser: JSON responses Browser->>Browser: Pure transforms (data-transforms.ts) Browser->>Browser: Render charts (Recharts / D3 / Chart.js) Browser->>WP: ThemeArticles: fetch WP API (live) alt WP unreachable Browser->>FS: fallback → articles.json end end
