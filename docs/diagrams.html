4. Theme Cross-References Between Data Files

Each theme is identified by a single themeKey (e.g. theme_miljo_sundhed) that links the theme config, the per-theme votes file, and the matching groupings inside the three All_* coalition files. The theme_votes_*.json files in turn cross-reference Danish-MEP disagreements (via vote_id) and feed deep-links into /latest-votes (via document_reference).

5. Build-Time vs Client-Runtime Data Flow

Temporal flow: at build-time only the WordPress tag-ID sync runs, then Next.js statically generates all pages. At runtime the browser fetches the static JSON files via SWR, plus theme pages call the WordPress REST API directly to lazy-load articles.

sequenceDiagram participant WP as WordPress participant Sync as sync-theme-tag-ids participant FS as data folder participant Next as Next.js SSG participant Browser as Browser rect rgb(230, 245, 230) Note over WP,FS: BUILD-TIME (prebuild + build) WP->>Sync: GET /wp-json/wp/v2/tags Sync->>Sync: build name to id index Sync->>FS: update data/themes/*.json (articleFilter.tagIds) Note right of Sync: On WP failure - warn and exit 0 (keeps previous tagIds) FS->>Next: read data/themes/*.json Next->>Next: generateStaticParams returns energi, forsvar, miljoe FS->>Next: read latest_votes.json and All_Pairwise_coalitions.json Next->>Next: generateSubDescription per visualisation Next->>Next: export static HTML and JSON to /out Note right of Next: No articles fetched at build-time end rect rgb(230, 235, 250) Note over Browser,FS: CLIENT RUNTIME Browser->>Browser: Load static HTML page Browser->>FS: useSWR /data/All_*.json Browser->>FS: useSWR /data/theme_votes_KEY.json (theme mode) Browser->>FS: useSWR /data/group-tooltips.json Browser->>FS: useSWR /data/committee_and_group_names.json FS-->>Browser: JSON responses Browser->>Browser: Pure transforms (data-transforms.ts) Browser->>Browser: Render charts (Recharts, D3, Chart.js) Note over Browser,WP: Tema page only Browser->>WP: ThemeArticles useSWR /wp/v2/posts (tags, per_page, _embed) WP-->>Browser: Article list (live) Note right of Browser: Spinner while loading, error message if WP unreachable end
